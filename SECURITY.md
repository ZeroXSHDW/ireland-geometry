# Security policy — Ireland Geometry

## Reporting a vulnerability

Please report suspected vulnerabilities privately by emailing [hello@zerodevllc.com](mailto:hello@zerodevllc.com) or using a private GitHub security advisory when available. Include the affected revision, a concise reproduction, impact, and any proposed mitigation. Do not publish credentials, private configuration, or exploit details in a public issue.

## Scope

The supported surface is the default branch, the latest review branch, repository automation, and the documented runtime or scripts. Treat credentials, tokens, host-specific paths, unsafe defaults, command injection, insecure deserialization, and supply-chain changes as security-sensitive.

## Handling

Reports are investigated against the affected revision and addressed according to severity and maintainer capacity. Please do not assume that acknowledgement promises a particular response time. Never commit real credentials or sensitive customer, device, or production data.
